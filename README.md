# ☕ Automated Java (OpenJDK) Installer for Linux

An interactive, lightweight Bash script to easily install any available version of Eclipse Adoptium OpenJDK on Ubuntu and Debian servers. Ideal for Minecraft servers, backend applications, and developers.

[![Bash](https://img.shields.io/badge/Language-Bash-4EAA25?logo=gnu-bash&logoColor=white)](https://www.gnu.org/software/bash/)
[![Platform](https://img.shields.io/badge/Platform-Ubuntu%20%7C%20Debian-E95420)](https://ubuntu.com)
[![Host](https://img.shields.io/badge/Optimized%20for-Ryzehosting%20KVM-6254fe)](https://ryzehosting.com)

---

## ✨ Features
- 🚀 **Interactive Version Selector:** Automatically fetches all active OpenJDK releases directly from the Adoptium API.
- ⚡ **Zero-Hassle Setup:** Automatically installs required dependencies (like `jq`) if missing.
- 🛠️ **Seamless Environment Setup:** Configures default Java paths and alternatives automatically.

---

## 📥 Quick Installation (One-Liner)

Run the following command on your server with `root` privileges:

```bash
curl -sSL https://raw.githubusercontent.com/RyzehostingNET/java-installer/main/install.sh | bash
```
